# 存正斋主人 - 儒家思想论集

这是一个基于GitHub Pages的个人网页，用于发布儒家理论和观点。

## 项目介绍

本项目旨在分享对儒家思想的理解与感悟，希望通过文字的力量，让更多人了解儒家文化的精髓，共同传承和弘扬中华优秀传统文化。

## 技术栈

- HTML5
- CSS3
- JavaScript
- Font Awesome
- GitHub Pages

## 项目结构

```
CZZweb/
├── index.html       # 主页
├── style.css        # 样式文件
├── script.js        # JavaScript文件
├── articles/        # 文章目录
│   └── ren-in-lunyu.html  # 示例文章
├── .gitignore       # Git忽略文件
└── README.md        # 项目说明
```

## 功能特性

- 简洁典雅的界面设计
- 响应式布局，适配不同设备
- 平滑滚动和动画效果
- 文章分类和展示
- 方便后续添加新文章

## 使用方法

1. 将本仓库克隆到本地
2. 在浏览器中打开index.html文件即可查看
3. 如需添加新文章，在articles目录下创建新的HTML文件，并在index.html中添加相应的链接

## 部署到GitHub Pages

1. 将代码推送到GitHub仓库
2. 在仓库设置中开启GitHub Pages功能
3. 选择main分支作为发布源
4. 等待几分钟，网站即可通过GitHub Pages访问
